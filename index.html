《小小王国战记》隐私政策

TapTap Android 测试版 · 草稿版本 0.1.0-test2

发布状态：待补齐并核验。 本草稿尚未覆盖 TapTap 未成年人合规认证 SDK 的最终数据流；不满 14 周岁监护人同意和广告限制流程未实现；TapADN 实际设备采集仍待真机核验。请勿作为正式政策提交。

一、运营者与范围

《小小王国战记》（“本游戏”）由 许珑伟（个人） 运营。个人信息保护联系邮箱：1766809821@qq.com。本草稿针对 TapTap Android 测试版、离线/局域网对局及玩家主动选择的 TapADN 激励视频。

二、游戏运行与联机

当前游戏代码没有玩家注册账号、姓名/手机号档案、位置或通讯录读取、分析遥测和崩溃上报，也没有玩家档案或对局进度本地存档。此说明不涵盖 Android 系统、TapTap 平台或第三方 SDK 的独立处理。

真人对战采用玩家主机权威的局域网 ENet/UDP 直连。玩家输入房主 IP 地址和端口后，设备使用连接所需的网络地址，并交换席位、游戏指令及本局状态。游戏业务代码不保存该地址；对局状态只在运行期间处理。房主是玩家设备，不是运营方互联网服务器。

三、TapADN 激励视频

玩家主动打开奖励面板并同意后，游戏才初始化 TapADN SDK（Android 5.3.2.0）并请求广告。当前只支持全屏激励视频，小窗暂不可用；广告播放期间对局继续运行。拒绝或关闭面板不影响游戏其他功能。

TapADN SDK 可能处理设备品牌/型号、系统版本、屏幕参数、语言/时区、CPU、可用存储、OAID、IP 地址、Wi-Fi 状态/信号、应用包名/版本、进程与前后台状态、广告交互、崩溃及性能数据，用于广告投放、效果衡量/归因、反作弊和 SDK 稳定性。字段、保存期限及合作方以实际启用模块和 TapADN 隐私政策为准。

游戏将电话状态、OAID、Wi-Fi 状态等自定义采集开关设为关闭，并限制个性化广告；但 TapADN 公开政策仍将 OAID 与 Wi-Fi 状态/信号列为必要信息。关闭开关后的实际传输及广告影响尚未真机核验，发布前需向 TapADN 确认。

四、广告奖励处理

TapADN 客户端奖励回调通过后，观看设备把随机申请编号、观看秒数和本局席位信息，经现有局域网连接交给房主。房主检查对局状态、时长上限和重复申请，再决定 Gold、Wood 或 Food 的随机数量并同步资源。未完成广告或 SDK 拒绝时不发奖。

奖励不使用独立公网验证服务。房主能够维护本局资源状态并拦截重复申请，但不能独立证明访客设备实际播放了广告或准确核验观看秒数；奖励仅用于休闲玩法，不用于付费、提现或竞技排名。

五、保存与共享

游戏自身的对局状态只在本局运行期间处理。TapADN SDK 在设备端按其服务处理广告所需信息，并可能依其政策与关联方、广告主、代理商及广告监测合作方共享必要信息；其具体保存期限以 TapADN 政策为准。本项目不会将奖励申请发送到独立公网奖励数据库。若最终 APK 增加其他 SDK 或网络服务，发布前须补充披露。

本游戏拟面向全年龄用户。目前尚未接入 TapTap 实名/防沉迷合规认证，也没有不满 14 周岁用户的监护人同意和激励广告限制流程。完成 SDK 接入、测试并确定监护人行权方式前，本草稿不能作为上线政策。
